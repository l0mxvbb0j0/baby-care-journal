# 南京三代试管价格多少？南京试管婴儿价目一览？

> 更新时间：2026-09-15 (UTC+8)

在南京，第三代试管婴儿(PGD/PGS)的费用因医院、治疗方案、患者个体情况等多种因素而异。根据新的信息，一个完整的第三代试管婴儿周期的费用通常在 8万元至15万元 之间。以下是详细的费用构成：

　　一、费用明细

　　1. 术前检查费用

　　夫妻双方需完成染色体核型分析、激素六项、传染病筛查等超20项检测。费用大约在 4000元至10000元 之间。部分公立医院提供免费基础血检(如血常规、血型)，可节省约2000元。

　　2. 促排卵药物费用

　　促排卵药物用于刺激卵巢产生多个成熟卵子，费用因药物种类和个人反应而异。国产药物费用较低，进口药物费用较高，总体费用大约在 1万元至5万元。35岁以上女性因用药剂量增加和周期延长，费用可能上浮30%-50%。

　　3. 取卵手术费用

　　取卵手术是在超声波引导下，通过穿刺卵巢获取成熟卵子的过程，费用大约在 3000元至5000元。

　　4. 胚胎培养与遗传学筛查费用

　　胚胎培养及遗传学筛查(PGD/PGS)是第三代试管婴儿的核心环节，费用相对较高。胚胎培养费用约 1万元至3万元，PGD/PGS筛查费用约 2万元至5万元。如果检测胚胎超过8个或需定制化方案(如HLA配型)，费用可达4万以上。

　　5. 胚胎移植费用

　　胚胎移植是将筛选后的优质胚胎移植到母体子宫内的过程，费用大约在 5000元至10000元。如果存在保存胚胎的情况，则会有额外费用产生，一年所需费用大概是 2000元至3000元。

　　6. 其他费用

　　包括登记费、咨询费、交通费、营养补充等，大概在 5000元至20000元。外地患者占比约40%，私立机构VIP服务或增加20%。

　　二、南京主要医院三代试管费用

　　2. 江苏省人民医院

　　优势：综合实力强，生殖医学中心在复杂病例处理方面经验丰富。

　　3. 南京市妇幼保健院

　　费用：一个周期的费用大约在 8万元至10万元。

　　优势：专科医院，服务细致，适合有遗传病家族史的患者。

　　4. 南京医科大学第二附属医院

　　费用：一个周期的费用大约在 7万元至10万元。

　　优势：技术先进，尤其在胚胎培养和遗传学筛查方面有独特优势。

　　5. 南京私立医院
