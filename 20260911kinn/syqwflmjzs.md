# 主动脉瘤的外科治疗

> 更新时间：2026-09-11 (UTC+8)

1.主动脉瘤概念、发病率及病死率
 主动脉瘤指真性动脉瘤、夹层动脉瘤及假性动脉瘤。真性动脉瘤瘤壁包括主动脉壁全层；夹层动脉瘤是指在主动脉内膜及中层发生撕裂后，循环血液经主动脉内膜破口，进入管壁中层内流动，向近远两侧将管壁中层结构分离开,它是主动脉瘤中最常见的；假性动脉瘤瘤壁仅含有主动脉外层及周围纤维组织。动脉瘤发病率为每年每100万人中10-20人发病。急性夹层主动脉瘤发生后若未得到及时治疗，其发病后早期12小时内病死率为13%, 24小时内病死率为21%, 48小时内病死率约36-72%，两周内病死率将达80%。
 2.主动脉瘤的病因
 主动脉瘤的病因仍不太清楚，老年患者中多数合并有高血压及动脉粥样硬化，而青年患者主要致病因素是Marfan综合征；其它一些致病因素包括主动脉中层退行性变、主动脉炎症、损伤、医源性、吸毒、二瓣型主动脉瓣等。
 3. 主动脉瘤治疗方法
 3.1 传统外科人工血管置换术：指对病变动脉瘤壁用人工血管进行置换，此法是经典治疗方法。但外科手术切除和人工血管移植，因手术复杂，难度较大，术后并发症及死亡率均较高，特别是对高龄和伴有其他系统疾病的患者。
 3.2 主动脉内带膜支架植入术 ：也称腔内隔绝术，通过介入方法将带膜支架植入主动脉内，当支架在主动脉腔内释放展开后，其近远端分别与病变近远端的正常动脉壁紧密附着，使病变处管腔与主动脉血流隔绝并逐步在瘤体内形成血栓，从而防止瘤体进一步增大和破裂。此法是近十年开始在临床使用的一种方法，具有微创、恢复快的特点，但对某些特殊部位的动脉瘤并不适用（如弓部动脉瘤），且由于该技术开展时间短，还未完全成熟，长期疗效还有待继续观察。
 3.3 Hybrid手术：是传统外科手术与腔内隔绝术相结合的方法，近几年才开始应用；主要应用于涉及主动脉弓部的动脉瘤。先通过外科手术将弓部供应大脑血液的分支动脉用人工血管搭桥于升主动脉，再用带膜支架腔内隔绝弓部的动脉瘤壁；此法主要在高龄及手术风险高的患者中使用。
 目前，外科人工血管术主要应用升主动脉瘤、A型夹层及复杂瘤颈的腹主动脉瘤。而其它部位及类型的主动脉瘤均可通过腔内隔绝术或Hybrid手术进行治疗。（胸心外科 龙小毛博士）
